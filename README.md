# Hues

### An atlas of concealed colour palettes.

**Hues** is a pocket-sized exploration of the colours hiding in everyday life. Step outside, notice the overlooked, collect colours from the world around you, and turn ordinary observations into a personal atlas of colour.

Instead of treating colour as just a code or a swatch, Hues gives every shade a connection to the real world.

## ✦ The Idea

The world is full of colour palettes waiting to be discovered—in weathered walls, fallen leaves, quiet streets, old buildings, and fleeting moments of light.

Hues encourages you to step away from the screen, explore your surroundings, and build a collection of colours inspired by what you actually see.

**Look closer. Find a shade. Keep its story.**

## ✦ What It Does

* **Discover Colours** — Explore shades inspired by the details of everyday surroundings.
* **Collect Palettes** — Build a personal archive of colours you encounter in the real world.
* **Preserve Observations** — Give collected shades context beyond their hexadecimal values.
* **Explore Your Atlas** — Revisit your discoveries as a growing collection of visual observations.
* **Touch Grass** — Make colour discovery a reason to step outside and engage with the world.

## ✦ Why Hues?

Most colour tools begin with a screen. Hues begins with the world outside it.

The project explores a simple idea: technology can encourage us to observe our surroundings rather than spend more time looking at a display.

It transforms an everyday walk into an opportunity for creative discovery, connecting digital colour collections with real-world experiences.

## ✦ Design Philosophy

Hues is designed to feel like a field journal for colour—not a conventional design utility.

Its visual language draws inspiration from:

* Natural colour relationships and balanced palettes.
* Editorial typography and playful composition.
* Colour specimens presented as objects worth noticing.
* A quiet, tactile aesthetic that celebrates imperfection and discovery.

The goal is to make collecting colours feel personal, exploratory, and rewarding.

## ✦ Built For

Hues is created for the **Hacktoberfest Open-Source AI Challenge — Week 1: Touch Grass**.

The challenge is to build something that encourages people to step away from their screens and reconnect with the world around them.

Hues approaches this through colour exploration, creative observation, and the simple pleasure of noticing what is often overlooked.

## ✦ Tech Stack

- **Frontend:** React 19
- **Styling:** CSS (custom styling)
- **Language:** JavaScript (ES Modules)
- **Build Tool:** Vite 8
- **Linting:** Oxlint
- **Package Management:** npm

## ✦ Getting Started

Clone the repository:

```bash
git clone https://github.com/rrane1307/Hues
```

Navigate into the project:

```bash
cd Hues
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
